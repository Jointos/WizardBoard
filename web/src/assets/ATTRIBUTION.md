# Icon attributions

- `portal.svg` / `portal.png` — a simplified twin-portal teleport glyph,
  inspired by the Noun Project “teleport” icon by **Lucas Helle**
  (https://thenounproject.com/icon/teleport-4215351/). The small badge uses an
  original simplified line drawing, not the original artwork. Used as the
  wizard buff (free-teleport) badge, recoloured green.
